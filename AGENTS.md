# Camada 3D

## Objetivo
Construir uma marca de produtos impressos em 3D, começando por vendas na Shopee e evoluindo posteriormente para uma plataforma própria de gestão da microfábrica.

## Prioridade atual
1. Vendas de Natal 2026 na Shopee
2. Catálogo/site Camada 3D
3. Gestão de produção e rentabilidade
4. Servidor caseiro / homelab
5. Assistente de IA por voz "Sol"

## Stack atual
- React 18
- Vite
- Tailwind CSS
- Lucide
- Dados de produtos ainda locais
- Sem backend atualmente

## Princípios
- Entregar em pequenas stories.
- Evitar overengineering.
- Não criar infraestrutura que não seja necessária para a venda inicial.
- Manter código simples e legível.
- Toda funcionalidade importante deve ter critérios de aceite.
- Custos de produção devem considerar filamento, energia, embalagem e outros custos.
- Produtos provenientes de plataformas como MakerWorld devem registrar origem e licença comercial.

## Direção futura
A plataforma deverá evoluir para permitir:
- Gestão de produtos
- Custos de produção
- Margem e lucro
- Lucro por hora de máquina
- Estoque
- Pedidos
- Planejamento de impressão
- Integração com servidor local
- Assistente de IA por voz
